Binggrae Melona (빙그레 메로나체) (font: resources/font/font_original.ttf)
Source: Binggrae Co., Ltd. font page https://www.bing.co.kr/news/media_font (download https://www.bing.co.kr/font/BinggraeMelona_TTF.zip); designed by YoonDesign Inc. (Im Kwangkyu, Park Soojin, Han Dohee)
Version: 1.000 (name table "Version 1.000;Build 20191004"; same 4,755,028-byte file as BinggraeMelona.ttf in Binggrae's current download zip)
Shipped as: BASE/Emus/shared/drastic/resources/font/font_original.ttf (skeleton/BASE/Emus/shared/drastic/resources/font/). The pinned advanced_drastic tarball (root Makefile DRASTIC_COMMIT) also contains this same font as resources/font/font.ttf, which `make setup` copies into build/BASE/Emus/shared/drastic/resources/font/ before the skeleton overlay.
License: proprietary freeware (Binggrae font license). No license file is distributed with the font (the official zip holds only the .ttf files) and the official site's "빙그레체 라이센스 보기" (view license) link is an empty javascript:void(0) anchor (checked 2026-10-07). Font name table copyright: "Copyright (C) BINGGRAE. and YoonDesign Inc. All rights reserved." / "Binggrae Melona is a trademark of BINGGRAE."

WARNING: the published terms state that the font may NOT be modified or redistributed and must be used only in the form in which it is distributed ("수정 및 재배포를 할 수 없으며, 배포되는 형태 그대로 사용해야 합니다"). Bundling the .ttf in a firmware release is redistribution of the font file itself, which these terms do not permit. Embedding in a program is listed as allowed, but that does not override the no-redistribution clause.
