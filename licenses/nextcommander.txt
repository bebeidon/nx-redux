NextCommander's repository contains no LICENSE/COPYING file and GitHub reports no license; the same is true of its parents OnionUI/app-DinguxCommander and gcwnow/DinguxCommander, and neither README.md nor README.txt nor the source headers state a license (checked 2026-10-07). The original DinguxCommander by Mia was published without a license: the maintainer of the separate rewrite od-contrib/commander (Gleb Mazovetskiy) recorded in commit 6023665431029ea63a7c83fdf215a9d14c2f6c1c (2021-06-28): "I've made multiple failed attempts to contact the author of the original code about the intended license. The original code and icons were published without a license." That rewrite was then relicensed MIT, but NextCommander descends from the gcwnow lineage, not from od-contrib/commander, so the MIT grant does not cover it. The only explicit license in the shipped program is the bundled SDL_gfx rotozoom code (Zlib), reproduced below. Fonts in Files.pak/res/ are covered by source-code-pro.txt.
