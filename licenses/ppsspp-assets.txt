PPSSPP runtime assets (fonts, PSP replacement system fonts, UI atlases, data files, post-processing shaders)
Source: https://github.com/hrydgard/ppsspp (assets/ directory); Roboto Condensed: https://github.com/googlefonts/roboto-classic; Inconsolata: https://github.com/googlefonts/Inconsolata (originally https://github.com/cyrealtype/Inconsolata)
Version: PPSSPP 1.20.4 (pinned commit 2a1700a7ee495310c52c85f9436652cc8f26e45e); Roboto Condensed 3.009 (2024); Inconsolata 3.001
Shipped as: .system/<platform>/paks/Emus/PSP.pak/PPSSPP/ for tg5040 and tg5050 (copied from workspace/<platform>/cores/output/ppsspp-assets/PPSSPP by the top-level Makefile), notably:
  - Roboto_Condensed-{Regular,Bold,Italic,Light}.ttf, Inconsolata-Regular.ttf
  - flash0/font/{jpn0,kr0,ltn0..ltn15}.pgf
  - font_atlas.zim/.meta, asciifont_atlas.zim/.meta, ppge_atlas.zim/.meta, lang/*.ini, shaders/*, vfpu/*.dat,
    compat.ini, compatvr.ini, knownfuncs.ini, langregion.ini, cheats.json, infra-dns.json, adhoc-servers.json, redump.csv
License: OFL-1.1 (Roboto Condensed, Inconsolata); GPL-2.0-or-later as part of PPSSPP (everything else, see notes; the PPSSPP license text ships next to the core as PSP.pak/LICENSE-ppsspp.txt)

Notes
-----
* Roboto Condensed: the shipped TTFs are Roboto Classic 3.009, whose name table states the SIL Open Font
  License 1.1 (not Apache-2.0 as older Roboto releases were): "Copyright 2011 The Roboto Project Authors
  (https://github.com/googlefonts/roboto-classic)" / "This Font Software is licensed under the SIL Open
  Font License, Version 1.1."
* Inconsolata-Regular.ttf: "Copyright 2006 The Inconsolata Project Authors
  (https://github.com/cyrealtype/Inconsolata)", Version 3.001, SIL Open Font License 1.1.
* flash0/font/*.pgf: these are NOT Sony's PSP firmware fonts. They are PPSSPP's own free replacement
  fonts: added to PPSSPP on 2013-02-27 by Henrik Rydgård in commit 1429d0206a "Add JPCSP's free font
  files." (from the JPCSP PSP emulator project, which is GPL-3.0 licensed), and redrawn/reworked by
  nassau-tk in 2020-2023 (PPSSPP PRs #13586, #13587, #13721, #13753, #13948 and later commits; kr0.pgf
  is nassau-tk's Korean font, see PPSSPP issue #13190). PR #13948 "PGF Fixed Bold & Italic property and
  camouflage the Font name" deliberately sets the internal font names to the Sony names
  ("FTT-NewRodin Pro Latin", "FTT-NewRodin Pro DB", "AsiaKNHH-SONY-uni") so games accept them; the glyph
  data is not Sony's. No separate license file exists for these fonts; they are distributed as part of
  the PPSSPP source tree under PPSSPP's GPL-2.0-or-later license (JPCSP origin: GPL-3.0). Exact
  licensing of the JPCSP originals is not documented upstream.
* *.zim atlases: generated by PPSSPP's atlastool from the bundled fonts and UI images; part of PPSSPP (GPL-2.0-or-later).
* shaders/: PPSSPP post-processing / texture-upscaling shaders, each with its own header where present:
  GNU-GPL (4xhqglsl, aacolor, cartoon, videoAA by guest(r)), 5xBR by Hyllian/Jararaca (GPL-2.0-or-later
  header; 5xBR-lv2 has an MIT-style permission notice), tex_2xbrz/tex_4xbrz ("DeSmuME team (GPL2+)" and Hyllian), AMD FidelityFX FSR
  (fsr_easu/fsr_rcas, MIT, Copyright (c) 2021 Advanced Micro Devices, Inc.), MMPX (MIT; tex_mmpx_adv
  Copyright (c) 2025-2026 by crashGG), NNEDI3 (GPL-3), psp_color (public domain); headerless ones are part
  of PPSSPP (GPL-2.0-or-later).
* redump.csv: PSP disc metadata (hashes, serials, titles) from the redump.org database, bundled by PPSSPP.
